=========================================================
Reawakened Hills - Local Static Images Directory
Folder: public/images/
=========================================================

You can save your local images directly into this folder.
Since Express serves the "public" folder statically, any image placed here
can be accessed in your HTML files using:

    <img src="images/your-image-name.jpg" class="gem-img" alt="...">
